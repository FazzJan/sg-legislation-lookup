# Data

- `pc-a.json` / `pc-b.json` — Penal Code offences from the **Criminal Procedure Code 2010 First Schedule** (472 entries, compact encoding). Self-hosted so the app does not depend on third-party repos at runtime.
- `extra.json` — Curated key sections from other Singapore Acts (POHA, MOA, GCA, GEWCA, CESOWA, LCA, DPA, Moneylenders, Computer Misuse).

Always verify against [sso.agc.gov.sg](https://sso.agc.gov.sg).
